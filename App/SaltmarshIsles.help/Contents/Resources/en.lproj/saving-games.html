Saving games

Your game saves itself after every move and reopens where you left off.

You can also keep up to 5 named games. On a Mac, use the File menu. On iPhone and iPad, use the Game button.

When all 5 are used, pick one to replace, or use its trash can in the Save Game window to delete it. Nothing is deleted on its own.

Loading a game replaces the one you're playing, so save it first if you want to keep it.
